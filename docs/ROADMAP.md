# Release scope

## Completed short campaign

Seven linked cases, including the four previously planned chapters; a resolved Iva storyline; three outcome-dependent endings; editable saved username; terminal, evidence, reports, debriefs, hints, deductions, and decoding; campaign records; original-save migration; persistent display settings; static build and local server.

The term complete refers to this authored short campaign, not every feature considered in the original planning document. The original 20–25-hour duration has not been built or measured.

## Optional future expansions

More contracts within each act, richer process/network simulation, arbitrary checkpoint rollback, concurrent-tab handling, full translation, original sound design, additional puzzles, public mission tooling, and expert challenge variants. None is needed to reach the existing endings.

## Release follow-up

Run the manual browser acceptance checklist in VERIFICATION.md, conduct external playtests, measure pacing and confusion, and decide public licensing and distribution. Browser and accessibility certification have not been performed here.
