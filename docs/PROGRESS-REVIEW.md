## Issues fixed

1. `boardLinking` survived case changes. Selecting a new-case record could form a cross-case pair and make subsequent save validation fail. Case changes now reset the selection, and the link mutation itself rejects stale IDs.
2. Notes had no input limit although saves reject text over 2000 characters. Input and mutation limits now agree; notes autosave after a short pause and on blur.
3. The order matcher accepted comma spacing, but the command parser required one token. Unquoted comma-separated lists now reach the order matcher correctly.
4. Checkpoint addition and old-slot deletion used separate transactions. Both now occur atomically.
5. Save status could show no pending writes while another queued write remained. A pending counter now tracks the full queue.
6. The map's generated gateway looked like a real case node. The revised map labels actual authored relationships and does not imply packet-level simulation.

## What is intentionally unchanged

The seven original case solutions and report scoring remain compatible. Practice is optional, so old completed cases do not need to be redone. Board notes remain scoped to the current case, as in the upload; export or checkpoint an attempt before replaying if its notes matter. Named checkpoint retention remains 12 per browser, oldest first. A single exported game save does not include every named checkpoint.

## Validation

54 automated tests pass, including the original 43. Added tests cover automatic recovery, nested/cross-case snapshot rejection, note/link bounds, all seven exercises, chronological false answers, guided prompts, order parser spacing, message IDs, uploaded-save compatibility, and audio lifecycle using a controlled audio API test double.

Build, source syntax, HTTP serving, runtime file parity, and ZIP integrity are checked. The save compatibility fixture was generated by the untouched uploaded engine and serializer, not hand-invented to fit the upgraded schema.

## Remaining limits

There is no real browser binary in the delivery environment. Visual rendering, native IndexedDB transactions, actual audio playback, and assistive technology have not been interactively verified. No external player testing or completion-time study has been performed. Tests of engine logic, serialized saves, and a mocked audio lifecycle do not prove those browser behaviors.

Before publishing, run the manual checks in VERIFICATION.md. The game remains a complete short authored campaign rather than the original proposed 20–25-hour title.
