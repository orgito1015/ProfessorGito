# Feature status after the upload review

All six requested feature areas are implemented in bounded form: named checkpoints and automatic recovery; evidence notes and visible links; varied optional exercises; interactive case map; three guidance modes; messages and optional effects/ambience.

Next priorities are browser acceptance tests, external playtesting, and pacing improvements. Future expansions could include archived cross-case boards, additional authored contracts, localization, and multi-tab write protection. These are not implemented in this release.
